## ② 되풀이되는 불만의 뿌리

1. **「그 신이 된다」는 고정 클래스 구조가 한 번도 바뀌지 않았다.**
   - 1차의 「유물 셋 → 발현 → 승급 전설」이 신화 개방 → 고른 신화 → 주신으로 이름만 바뀌었다.
   - 고친 것은 여는 길(숙련 → 성소 고르기 → 조각 셋)과 칸뿐이다. 주신이 무기·리듬·궁극기·패시브 전부·피해 배율을 정하고, 단계가 전설로 오르는 중심은 그대로다.
   - 다른 신의 몫은 오히려 계속 줄었다. 상시 효과 → 메아리 → 수집 보너스 +4% → 빌린 패시브 하나.
   - 같은 불만이 10-20(「한 클래스에 묶인 느낌」), 10-28(「바로 토르」, 「클래스가 되는 게 아니라 빌려 쓰기」), 10-29(「개선됐냐」)에 나왔다.

2. **성장이 덩어리지고, 축은 많은데 축마다 조금씩이다.**
   - 관련 의견은 「단계가 없다」(10-27), 「막대 큰 덩어리가 지루하다」(10-28), 「장비 하나로는 체감이 어렵다」(10-28)다.
   - 재 본 값: 처음 6분에 힘이 ×3이 되고 그 뒤 34분 동안 ×1.6뿐이었다(TIMELINE 1.1). 신화를 하나 더 열면 +1% 꼴이었다(6.2).
   - 지금도 남은 것:
     - 신 단계 2·3이 1500·3000 막대에 성소 전설로 오른다.
     - 영웅 장비 고유 효과 열둘은 카드의 글뿐이고 돌지 않는다(`.unique`는 `gearCard.ts`만 읽는다).
     - 수련의 큰 마디는 수치 묶음이다.
     - 장비 비교 카드에 한 줄 결론이 없다.
     - E240 성장 박자는 시작하지 않았다.

3. **사용자가 원한 순환(RI)이 핵심 자리에서 계속 밀려났다.**
   - 흐름: E4.5에서 사용자 요청으로 다섯 겹 순환을 만듦 → 2차에서 윤회 없앰(Claude 추천을 사용자가 받음) → RI 원리를 위협 단계·시련·균열·성좌판·편의로 옮김 → E21에서 모두 엔딩 뒤로 숨김.
   - 그래서 지금 90분 데모는 한 줄로 가는 장 흐름이다. 다시 돌며 곱으로 커지는 고리가 없다.
   - 사용자가 RI를 요구한 것은 이번이 세 번째다(10-17, 10-21, 10-29).

4. **빌드 선택이 싸우는 방식을 바꾸지 못한다.**
   - 원천을 몰아도 「누르는 것은 같다」(6.2 반쯤).
   - 시련·균열 축복도 대부분 수치다.
   - 유물은 한때 4배로 다른 선택을 덮었다가, 이제 그 신화를 골랐을 때만 깨어난다.
   - 빌린 칸은 패시브 하나뿐이다.
   - 「토르 3 + 로키 1을 써 볼 이유」(E6)부터 「두 번째 신을 넣으면 싸우는 모습이 달라진다」(E237)까지, 확인을 받은 적이 없다.

5. **보이는 것과 전해지는 것을 사용자가 먼저 찾아낸다.**
   - 사용자가 직접 짚은 것: 탭이 다 열려 복잡함, 성소 목표를 모름, 카드 표현이 모자람, 장비 모양 없음, 모자가 머리 색을 가림, 대사 투, 공격 모션 버그.
   - 대부분 고쳤지만 늘 사용자가 먼저 찾았다(「QA를 제대로 안 한 것 같다」). 무기 동작이 잘 안 보이는 것(E18 반쯤)과 유물 그림은 아직 남았다.

6. **확인 대기와 결정 뒤집기가 쌓여 기획이 흔들린다.**
   - 「사용자 확인 대기」 기본안이 E14부터 E239까지 열 개 넘게 쌓였고, E235~E239 체크리스트는 모두 대기 중이다.
   - 결정이 여러 번 바뀌었다: 두 번 클릭 → 없앰, 첫 신화를 성소에서 고르기 → 조각, 자동 줍기를 처음부터 → 엔딩 뒤, 마을을 가운데 → 남쪽 끝.
   - TIMELINE 4장(막간이 있는 E22 흐름)과 MYTHBUILD 5장(첫 안), 지금 코드가 서로 다른 시점을 말한다.
   - 휴대폰 fps는 한 번도 확인받지 못했다. 렌더 540은 픽셀 수 약 ×1.6, 삼각형은 51만으로 main 44만보다 많다.

## ③ 사용자가 정해 둔 원칙, 그리고 순환 요청과 부딪히는 예전 결정

### 지금도 살아 있는 원칙

- **조작 최소화:** 클릭(톡) 하나뿐이다. 땅을 누르면 이동만 하고 싸우던 중이어도 빠져나간다. 적을 누르면 그 적을 공격한다. 멈추면 둘레 적을 자동 공격한다. 두 번 클릭은 없고 버튼을 늘리지 않는다 (CLAUDE.md 원칙 1, decisions 10-23).
- **휴대폰:** 세로 화면만(사용자가 추천과 다르게 고름), 떠다니는 조이스틱(원은 누른 자리에 고정), 톡 = 클릭, 두 손가락 확대·축소. 태블릿은 기본안.
- **텍스트 최소화:** 전투 화면 글은 몬스터 이름표 한 줄까지만, 패널은 글이 필요 없게. 대화 장면만 예외이고, 세계 안의 말투로 쓴다.
- **보이는 방식:** 2D처럼 보이는 3D, 코드로 만드는 복셀(10-27 선택), 가장 크게 확대했을 때 기준의 선명도, 디자인 토큰·갈무리 글꼴. 실행하면 바로 게임이 시작된다.
- **싸워야 들어온다:** 마을 공방(저절로 쌓이는 생산)과 오프라인 시간 저축은 넣지 않는다. **전투 자체는 자동화하지 않는다** (REDESIGN 10.3·10.5).
- **윤회(전체 초기화)는 없앤다:** 「쌓은 게 남고 더 높은 곳으로」. 안쪽 리셋은 균열(임시 축복)에만 둔다 (2판, Claude 추천을 사용자가 받음).
- **신화와 원천:** 원천은 장비에서 오고 신화와 묶지 않는다. 각인은 없다. 열린 신화는 영구다.
- **세계:** 하나로 이어진 세계를 한 줄로 잇고 마을은 북유럽 끝이다. 웨이포인트는 처음부터, 탈것은 둘째 신화권부터.
- **신화 빌드(추천대로):** 신위 칸, 조각 셋(흔적 → 사냥 → 수호자), 신마다 다른 수호자.
- **성장 박자:** 1~2분마다 작은 걸음, 5분마다 새로 열리는 것, 15~20분마다 큰 체크포인트. 막대 하나가 3분 넘게 홀로 차지 않는다. 목표 한 줄은 2분 안에 닿는 일이다.
- **열리는 차례:** 정보 화면 탭은 쓸 일이 생길 때 하나씩 연다. 한 번에 새 장치 하나.
- **줍기와 수련:** 떨어진 장비는 밟거나 눌러서 줍고, 자동 줍기는 엔딩 뒤다. 수련은 언제든 무료로 되돌린다.
- **개발 모드:** 평소와 똑같이 플레이하고 패널만 더한다.
- **QA:** 체크리스트는 Claude가 사람 눈으로 본다.
- **데모:** 90분, 북유럽+그리스, 마지막 보스는 우트가르드의 왕.
- **유지할 긍정 반응:** 소리, 외형, 「발현하니 확 세진다」.

## ④ 재편 설계가 꼭 지켜야 할 것과 꼭 고쳐야 할 것

### 꼭 지켜야 할 것

1. **조작:** 클릭·톡 하나, 버튼을 늘리지 않음, 자동 공격, 땅 = 이동. 휴대폰 세로·조이스틱·두 손가락.
2. **글:** 텍스트 최소화, 세계 안의 말투, 목표 한 줄은 2분 안의 다음 일.
3. **들어오는 방식:** 재료·장비는 싸워야 들어온다. 공방·오프라인 시간·전투 자동화는 없다. 장비는 밟거나 눌러서 줍는다.
4. **이미 정한 구조:** 깨운 신은 영구, 한 줄 세계·웨이포인트, 조각 셋·수호자(사용자가 고른 것), 수련 무료 되돌리기, 탭 차례로 열기.
5. **큰 순간:** 순간 네 등급. 큰 체크포인트는 장면에 큰 힘(×1.3 이상이나 싸우는 방식 변화)이 따른다. 「확 세진다」 쾌감을 지킨다.
6. **코드 규칙:** 시스템은 버스로만 주고받는다. 수치는 `src/data/`, 색·글꼴은 디자인 토큰. 옛 저장은 옮기기로 깨지지 않게 한다. `npm run check`·봇·feel-qa·power-curve로 지킨다. 그리기 호출은 E18 기준 +30% 안.
7. **범위:** 데모(북유럽+그리스, 90분, 우트가르드의 왕), 코드 복셀.

### 꼭 고쳐야 할 것

1. **고정 클래스 발현을 해체한다.**
   - 지금 고칠 곳: `BuildState.ts`에서 `chosen[0]`이 정하는 공격 모션·공격 속도·피해 배율·궁극기·외형, 빌린 칸이 패시브 하나뿐인 것.
   - 무기(동작)·리듬·궁극기·패시브를 서로 다른 신에서 고를 수 있게 한다. 「한 신이 되는」 순간을 「여러 신의 조각을 끼우는」 구조로 바꾼다.
2. **순환을 90분 안에서 돌린다.**
   - 첫 바퀴는 15~20분 안에 끝난다.
   - 리셋할 때 고르는 갈래가 있고, 바퀴마다 곱으로 쌓이며, 다음 바퀴가 빨라지는 게 체감돼야 한다.
   - 엔딩 뒤로 숨긴 위협·시련·균열·성좌판·편의는 순환 층으로 다시 놓거나 걷어낸다.
3. **성장 덩어리를 없앤다.**
   - 3분 넘게 홀로 차는 막대를 0으로 (신 단계 1500·3000 막대와 성소 전설).
   - 영웅 장비 고유 효과가 실제로 돌게 한다(지금은 글뿐).
   - 수련 큰 마디는 싸우는 방식을 바꾸는 것으로, 장비 비교는 한 줄 결론으로.
   - 엔딩 50~52분을 목표 60~80분으로 맞춘다.
4. **장치를 정리한다.**
   - 지금 겹쳐 있는 것: 수집 보너스·수련·원천 각성·위협·시련·균열·축복·성좌판·편의.
   - 이것을 몇 개의 순환 층으로 묶는다.
   - 남은 옛 갈래를 걷어낸다: 유물로 신화를 여는 길(`relicsOpenMyths`), 그리스의 옛 성소 고르기(`MythChoice`), 시련·성좌판 예외 갈래.
5. **코드를 다시 나눈다.**
   - 큰 파일: `Game.ts`는 1275줄이다(2차 초 957줄에서 나눴는데 다시 커짐). `schema.ts` 875줄, `regionMap.ts` 916줄, `Giant.ts` 846줄.
   - 저장은 v13까지 올라왔으니 옮기기 사슬을 정리한다.
6. **성능을 다시 잰다.** 렌더 540(픽셀 수 약 ×1.6)과 삼각형 51만으로 `bench.mjs`를 재고, 휴대폰 fps를 기준으로 최적화한다.
7. **문서를 하나로 맞춘다.** DESIGN·TIMELINE·MYTHBUILD를 같은 시점으로 맞추고, 확인 대기 기본안은 추천안으로 확정해 적는다.
8. **남은 의견을 재편에 넣는다.**
   - 그리스 조각·수호자·탈것(E241)
   - 유물 그림·입은 모습·신화 무기 다시 그리기
   - 유물표(E6, 얻으면 켜지는 수집표)
   - 휴대폰 소리 재확인, 종장 시간
9. **답하는 방식을 고친다.** 사용자가 직접 물으면(「개선됐냐」) 예·아니오와 근거부터 답한다. 예전에 바로 답하지 않은 것이 오늘의 화로 이어졌다.
