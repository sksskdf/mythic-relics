# 템빨용사 (Overgeared Hero: Merge RPG) 아이템 조합 조사 (2026-10-29)

> 순환 재편 설계의 근거 자료. 웹 페이지 원문은 이 환경에서 열리지 않아 검색 요약에서 뽑았다. 등급별 수치·합치는 개수(2냐 3이냐)는 확인하지 못했다.

## 구조
- 판 안(5분 안팎, 판이 끝나면 사라짐): 상점에서 산 아이템을 격자 가방에 놓는다. 같은 것 2~3개 → 한 단계 높은 등급. 서로 다른 재료를 붙여 두면 다음 라운드에 새 아이템(조합식, 실루엣 "???" 도감). 전설은 합쳐야만 나온다.
- 판 밖(남음): 바깥 장비를 같은 부위 사본으로 겹쳐 올린다(영웅 +1~+3 → 전설 = 영웅 +2 세 벌 → 신화). 분해로 얻는 "원형"이 먹이를 대신한다. 도감 첫 제작 보상, 가방 확장.
- 순환: 판 밖 장비·영웅 → 판 안 상점·합치기·자동 전투 → 판 끝 보상 → 바깥 장비 합치기 → 다음 판.

## 재미의 원리
1. 합치면 바로 세진다 (낮은 것이 쏟아져 위로 합쳐지는 흐름)
2. 합쳐야만 나오는 최상위 등급이 목표가 된다
3. 언제 합칠지 고르는 판단 (칸 압박: 합치면 자리가 빈다)
4. 실루엣 도감이 만드는 발견 욕구
5. 짧은 판, 한 판 더

## 불만
- 같은 사본 여러 벌을 갈아 넣는 무게, 과금 묶인 가방 크기, 초반 답답함

## 우리 게임에 옮길 때 (조사 에이전트 제안)
- "같은 것"을 넓게: 같은 부위 + 같은 등급 셋 → 다음 등급 하나 (보통 27개 = 영웅 하나), 수치 칸 하나 더
- 「모두 합치기」 단추 하나, 마을(대장간)에서. 버튼을 늘리지 않는다
- 장비 단계(땅 단계)는 섞지 않는다
- 분해와 겹치지 않게 주 경로를 하나로
- 칸·가방 압박이 있어야 합치는 판단이 생긴다
- 드랍 체감이 1/3로 줄므로 곡선을 다시 맞춘다
- 사본을 정확히 요구하지 않는다 (먹이는 넓게, 단계는 짧게)
