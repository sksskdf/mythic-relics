# 문제 해결 기록

겪은 문제와 고친 법. 비슷한 증상이 보이면 먼저 여기를 본다. 새로 겪으면 더한다.

## 게임·봇

| 증상 | 원인 | 해결 |
| --- | --- | --- |
| 적 시험에서 보스 셋을 못 끝냄 | 봇이 피하다 마을 출구를 밟아 다른 땅으로 넘어감 | 봇이 출구를 피함(`EXIT_CLEAR` 3.5), 시험에서는 `Game.exitsLocked`로 출구를 잠금 |
| 귀신 셋이 도깨비불을 끝없이 부름 (91초, 피격 56) | 부르기에 상한이 없음 | 둘레에 넉넉하면 부르지 않게 (무리 상한 ×1.5, 전체 상한 24) |
| E8 뒤 기본 봇이 느리거나 승급 못 함 | 정예 방패병을 정면에서만 쳐 처치가 멈춤, 거인 왕을 못 잡음 | 공격하는 동안(예고·회복) 방패가 내려가게, 정예 확률 0.2·생명력 낮춤, 거인 왕 던지기 약화, 미드가르드 적 생명력 낮춤 |
| 아마테라스 봇이 30분 동안 승급 못 함 (E7) | 샛길이 보스 15m 옆을 지나 거인 왕이 깨고 끝까지 쫓아옴 | 보스를 길에서 떼고 무리 간격을 넓힘, 거인 왕은 30m까지만 쫓음 |
| 클래스 둘이 섞여 발현 못 함 (E6) | 칸이 토르 2·로키 2로 참 | 가방까지 합쳐 발현할 수 있으면 알림, 봇은 바꿔 낌 |
| 전설이 끝나지 않고 봇이 25분 동안 승급 못 함 (E11-06) | 전설은 소환한 적이 모두 사라져야 끝나는데, 적 하나가 결계 밖으로 밀려나 결계에 갇힌 주인공이 닿지 못함 | 결계가 적도 막게: `Legend.keepInside`가 밖으로 나간 적을 안으로 되돌림 (`tests/legend.test.ts`) |
| 정보 화면에서 처음 벼리거나 위협 단계를 올리면 화면이 멈춤 (중간 점검) | 대화 장면이 HUD를 숨기는데 정보 화면·일시 정지 창이 HUD 안에 있어 함께 사라지고, 게임은 창이 열린 채라 멈춰 장면도 끝나지 않음 | 창이 열려 있거나 다른 장면 중이면 장면을 미뤘다가 창을 닫은 뒤 차례로 연다(`Game.story`), 대화 중에는 Esc·창 벗어나기로 일시 정지하지 않음 |
| 맵 밖·결계 밖을 누르면 벽에 붙어 계속 걷고 싸우지 않음 (중간 점검) | 길찾기가 맵 밖 목표를 그대로 돌려주고 결계를 모름. 걷는 동안은 싸우지 않음(E12-08) | `HeroController.moveTo`가 목표를 맵·결계 안으로 당기고, 막혀 걸음의 1/4도 못 나아가면 0.5초 뒤 멈춤 |
| 균열에서 필드로 워프하면 그 필드 적이 균열 세기 (중간 점검) | 균열 배율을 균열이 끝날 때에야 되돌림 | 균열을 나가면 `encounter.resetAll()`, 균열 배율은 `Encounter.arenaThreat`처럼 따로 둠 |
| 균열 보스 층에서 싸우다 균열이 끝나 버림 (기술 부채 정리 때 봇 두 판 중 하나) | 나가는 문 곁의 적에게 다가가는 목적지도 "문으로 걸어감"으로 쳤다 | 땅을 눌러 걷는 중(`orders.order.kind === 'move'`)일 때만 문을 연다. 스모크가 적을 쫓다 밟는 경우도 본다 |
| 쓰러져 있는 동안 날아가던 망치·고리가 공중에 멈춤 | 쓰러지면 유물 효과를 아예 돌리지 않음 | 적 목록을 비운 채 돌려 연출만 마저 움직인다. 쓰러진 동안 회복이 들어와도 되살아나지 않게 `PlayerCombat.heal`이 막는다 |
| 첫 신화 때 신화 개방 장면 넷(대사 열두 줄)이 건너뛸 수 없이 이어짐 | 장면을 미뤘다 차례로 여는 대기열(중간 점검)과, 고른 신화가 없으면 그 신화권 넷이 함께 열리는 규칙이 겹침 | 신화 장면이 떠 있거나 기다리면 다음 신화 장면은 그 신화를 처음 고를 때(`manifested`) 연다 (`Storyline`, `tests/storyline.test.ts`) |
| 지역을 돌수록 GPU 형상이 늘어남 | 땅 물건·원천 고리·발자국·던지는 유물 모양을 지울 때 `geometry.dispose`를 안 함 | 같이 쓰는 모양은 모듈 상수로, 따로 만든 것은 지울 때 내림 (`Pickups.discard`, `disposeGeometries`) |
| 지역 들어가기 362ms | 소품·테두리 메시 | 테두리 합치기를 해 봤으나 그리기 호출이 줄지 않아 되돌림 |

## 테스트·도구

| 증상 | 원인 | 해결 |
| --- | --- | --- |
| vitest에서 `theme.css?raw`가 빈 글 | vitest가 CSS를 기본으로 처리하지 않음 | `vite.config.ts`의 `test.css.include: [/theme\.css/]` |
| 아트 테스트 실패: 나타·해모수 잔상이 위험색 | 붉은 주황이 `DANGER_HUE_GAP` 25도 안 | 나타 잔상 #ffb02a, 해모수 잔상 #ffc040 |
| 설산 길 대비 테스트 실패 | 밝기 차이 규칙이 너무 좁음 | 밝기 또는 채도 차이로 넓힘 |
| 적 모음 스크린숏에 칼질 자국 | 게임이 돌아가며 공격 | 메뉴를 열어 멈춘 채로 찍음, 보스 자르는 범위를 넓힘 |
| `npm run check`가 실패했는데 커밋됨 | 파이프 뒤 `tail`이 종료 코드를 삼킴 | 늘 `set -o pipefail` |
| 몬스터 이름표가 사라지지 않고 남음 | 지역 이동·전설 실패로 지운 거인(`Encounter.remove`)이 `dispose`만 되고 상태는 살아 있어, 공격 대상·커서 대상이 계속 붙잡음. 커서가 창 밖에 나가도 마지막 위치를 가리킴 | `Giant.dispose`에서 쓰러진 상태로 둠, 커서가 화면 밖이면 커서 대상 없음 |
