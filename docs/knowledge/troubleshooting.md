# 문제 해결 기록

겪은 문제와 고친 법. 비슷한 증상이 보이면 먼저 여기를 본다. 새로 겪으면 더한다.

## 게임·봇

| 증상 | 원인 | 해결 |
| --- | --- | --- |
| 적 시험에서 보스 셋을 못 끝냄 | 봇이 피하다 마을 출구를 밟아 다른 땅으로 넘어감 | 봇이 출구를 피함(`EXIT_CLEAR` 3.5), 시험에서는 `Game.exitsLocked`로 출구를 잠금 |
| 귀신 셋이 도깨비불을 끝없이 부름 (91초, 피격 56) | 부르기에 상한이 없음 | 둘레에 넉넉하면 부르지 않게 (무리 상한 ×1.5, 전체 상한 24) |
| E8 뒤 기본 봇이 느리거나 승급 못 함 | 정예 방패병을 정면에서만 쳐 처치가 멈춤, 거인 왕을 못 잡음 | 공격하는 동안(예고·회복) 방패가 내려가게, 정예 확률 0.2·생명력 낮춤, 거인 왕 던지기 약화, 미드가르드 적 생명력 낮춤 |

| 맵 밖·결계 밖을 누르면 벽에 붙어 계속 걷고 싸우지 않음 (중간 점검) | 길찾기가 맵 밖 목표를 그대로 돌려주고 결계를 모름. 걷는 동안은 싸우지 않음(E12-08) | `HeroController.moveTo`가 목표를 맵·결계 안으로 당기고, 막혀 걸음의 1/4도 못 나아가면 0.5초 뒤 멈춤 |
| 균열에서 필드로 워프하면 그 필드 적이 균열 세기 (중간 점검) | 균열 배율을 균열이 끝날 때에야 되돌림 | 균열을 나가면 `encounter.resetAll()`, 균열 배율은 `Encounter.arenaThreat`처럼 따로 둠 |
| 균열 보스 층에서 싸우다 균열이 끝나 버림 (기술 부채 정리 때 봇 두 판 중 하나) | 나가는 문 곁의 적에게 다가가는 목적지도 "문으로 걸어감"으로 쳤다 | 땅을 눌러 걷는 중(`orders.order.kind === 'move'`)일 때만 문을 연다. 스모크가 적을 쫓다 밟는 경우도 본다 |
| 쓰러져 있는 동안 날아가던 망치·고리가 공중에 멈춤 | 쓰러지면 유물 효과를 아예 돌리지 않음 | 적 목록을 비운 채 돌려 연출만 마저 움직인다. 쓰러진 동안 회복이 들어와도 되살아나지 않게 `PlayerCombat.heal`이 막는다 |
| 첫 신화 때 신화 개방 장면 넷(대사 열두 줄)이 건너뛸 수 없이 이어짐 | 장면을 미뤘다 차례로 여는 대기열(중간 점검)과, 고른 신화가 없으면 그 신화권 넷이 함께 열리는 규칙이 겹침 | 신화 장면이 떠 있거나 기다리면 다음 신화 장면은 그 신화를 처음 고를 때(`manifested`) 연다 (`Storyline`, `tests/storyline.test.ts`) |
| 뒷걸음치는 적·원거리 몬스터를 누르면 공격 모션만 엄청 빠르게 되풀이하며 따라감 (사용자, 2차 스프린트 뒤) | 공격 지시가 사거리 경계(−0.25m)에서 멈췄다 걸었다 하고, 걸으면 휘두르기가 끊김. 멈출 때마다 첫 타 시작(궤적·소리·내딛기)만 매 프레임 되풀이. 봇은 지시를 쓰지 않고 수치만 봐서 못 잡음 | `HeroOrders.updateAttack`: 시작한 휘두르기는 끝까지(그동안 쫓지 않음), 쫓을 땐 사거리 안쪽 0.6m까지, 멈춘 뒤엔 사거리를 벗어나야 다시 쫓음. `tests/orders.test.ts`, `scripts/feel-qa.mjs`(플레이어처럼 눌러 싸우며 끊긴 휘두르기·깜박임·헛휘두르기·붙잡힘을 잡음) |
| 지역을 돌수록 GPU 형상이 늘어남 | 땅 물건·원천 고리·발자국·던지는 유물 모양을 지울 때 `geometry.dispose`를 안 함 | 같이 쓰는 모양은 모듈 상수로, 따로 만든 것은 지울 때 내림 (`Pickups.discard`, `disposeGeometries`) |
| 지역 들어가기 362ms | 소품·테두리 메시 | 테두리 합치기를 해 봤으나 그리기 호출이 줄지 않아 되돌림 |
| 이어진 세계(E19)를 붙이자 시작 화면이 초당 1프레임, 스모크가 첫 프레임에서 시간 초과 | 이웃 칸까지 숲을 한 칸 통째(InstancedMesh 하나)로 그려 시야 거르기가 안 되고, 깊은 숲까지 그림자를 드리움 (삼각형 288만) | 숲을 10m 네모마다 나누고, 트인 땅에서 6m 넘는 깊은 숲은 성기게·크게·그림자 없이 (103만). `renderer.info`로 그림자 켬/끔·숲 숨김을 견주어 원인을 찾음 |
| 걸어서 넘어간 뒤 주인공이 멈춤 | `orders.shift`가 옛 땅의 길찾기 격자로 길을 다시 찾음 | 길찾기·`hero.area`를 새 땅으로 바꾼 뒤에 `orders.shift` |
| CI 스모크 한 판이 첫 대기(10프레임, 15초)에서 시간 초과 (다른 판은 통과) | 시작 화면이 이웃 조각까지 그려 무거움: 이웃 땅 바닥이 한 덩어리라 화면 밖에서도 통째로 그려지고(칸마다 3만 삼각형), 숲 네모(10m)가 커서 화면 밖 나무까지 그림, 처음 쓰는 인스턴스 셰이더 컴파일로 1초 멈칫 | 바닥을 25m 네모로 나눔(법선은 기울기로 구해 네모 경계에서 빛이 안 끊김), 숲 네모 6m, 그림자는 맨 앞줄(3m)만, 깊은 숲은 칸을 두 배로 줄인 단순한 나무. 시작 화면 삼각형 112만 → 52만(main 43만), 10프레임까지 7.3초 → 5.8초(main 4.8초). 러너 편차를 감안해 첫 대기를 30초로 |
| 봇이 가끔 25분 안에 2단계를 못 감 (CI 한 판, 로컬 서른 판에 한두 번) | 마을로 돌아가려는데 통로를 다 걸어야 넘어가서(E19), 쫓아오는 무리의 공격 예고를 피하기만 되풀이하다 필드를 못 벗어남 (`want: village`, 2단계 피하기) | 떠나는 길이면 생명 50% 이상일 때 예고를 피하지 않고 걸어 나감(`autoplay.ts`). 이웃 땅 무리는 그 땅 바위를 비켜 세우고, 깨울 때 집 자리를 빈 칸으로. 실패한 판은 `playtest.mjs`가 끝난 자리와 살아 있는 적을 찍는다 |
| 넘어간 직후 몇 프레임 멈칫 (조각 하나 35~55ms) | 이웃 조각을 한 번에 지음, 땅 색 칠할 때 칸마다 모든 길까지 거리를 잼 | 땅·숲·소품 단계로 나눠 프레임마다 한 단계(`chunkSteps`), 길마다 둘레 네모 밖이면 건너뜀 |

## 테스트·도구

| 증상 | 원인 | 해결 |
| --- | --- | --- |
| vitest에서 `theme.css?raw`가 빈 글 | vitest가 CSS를 기본으로 처리하지 않음 | `vite.config.ts`의 `test.css.include: [/theme\.css/]` |
| 아트 테스트 실패: 나타·해모수 잔상이 위험색 | 붉은 주황이 `DANGER_HUE_GAP` 25도 안 | 나타 잔상 #ffb02a, 해모수 잔상 #ffc040 |
| 설산 길 대비 테스트 실패 | 밝기 차이 규칙이 너무 좁음 | 밝기 또는 채도 차이로 넓힘 |
| 적 모음 스크린숏에 칼질 자국 | 게임이 돌아가며 공격 | 메뉴를 열어 멈춘 채로 찍음, 보스 자르는 범위를 넓힘 |
| `npm run check`가 실패했는데 커밋됨 | 파이프 뒤 `tail`이 종료 코드를 삼킴 | 늘 `set -o pipefail` |
| 몬스터 이름표가 사라지지 않고 남음 | 지역 이동·전설 실패로 지운 거인(`Encounter.remove`)이 `dispose`만 되고 상태는 살아 있어, 공격 대상·커서 대상이 계속 붙잡음. 커서가 창 밖에 나가도 마지막 위치를 가리킴 | `Giant.dispose`에서 쓰러진 상태로 둠, 커서가 화면 밖이면 커서 대상 없음 |

| `checklist-qa.mjs`의 장면이 `page.goto: Timeout`으로 줄줄이 실패 (E21) | e12-1이 첫 페이지를 닫지 않은 채 미드가르드를 새로 열었고, 이어진 세계(E19)라 이웃 땅까지 짓느라 30초를 넘김. 실패한 장면의 페이지가 남아 다음 장면까지 느려짐 | 두 번째 페이지를 열기 전에 첫 페이지를 닫고, 처음 여는 시간을 90초까지 기다리며, 장면이 실패하면 열린 페이지를 모두 닫는다 |
| 정보 화면 탭에 `hidden`을 붙였는데 그대로 보임 (E21) | `.menu__tab { display: flex }`가 `[hidden]`의 기본 `display: none`을 덮음 | `.menu__tab[hidden] { display: none }`을 더함. 스모크는 `b.hidden`만 봐서 못 잡았다 |
| 봇이 우트가르드에서 거인 왕에게 닿지 못하고 70분을 맴돎 (E22) | 보스가 목표라 곧장 보스로 걸어가다가, 가는 길 무리의 공격 예고를 피하느라 되돌아오기를 되풀이 (보스는 내내 idle, 거리 30~69m) | 보스 목표여도 둘레 9m 안에 다른 적이 있으면 먼저 치우고, 비었을 때만 보스로 간다 (`autoplay.ts` step 16) |
| 생성 스크립트(`gen-finale.mjs`·`gen-regions.mjs`)가 `vite.config.ts`를 불러오다 지역 검사에 걸림 (E22) | vite 설정이 불러올 때 regions.json을 검사하는데, 고치는 중인 파일이라 아직 틀림 | `createServer({ configFile: false })`로 설정 없이 띄우고, 문 없는(검사를 통과하는) 파일을 먼저 쓴 뒤 모듈을 불러와 문을 단다 |
| 스크래치 폴더에 둔 `.mjs`가 `vite`·`playwright-core`를 못 찾음 | 노드 모듈은 스크립트가 있는 폴더 위로만 찾는다 | 저장소 `scripts/` 안에 잠깐 두고(`.` 이름) 돌린 뒤 지운다 |
| CI 스모크의 엔딩 확인이 `page.goto: Timeout 90000ms` (E22) | 앞 페이지(게임이 도는 중)를 열어 둔 채 새 페이지를 열어, 소프트웨어 렌더링 CPU를 둘이 나눠 씀. 로컬은 통과하고 CI만 넘김 | 새 페이지를 열기 전에 앞 페이지를 닫고, `load` 대신 `domcontentloaded` 뒤 게임이 도는 것(`playing`)을 120초까지 기다린다 |
| 스모크를 돌린 뒤 포트 4173에 `vite preview`가 남아, 하네스가 다음 검사를 막음 (E23) | 스모크가 `npx`만 끄고 그 아래 vite는 남았다 | 미리보기 서버를 묶음으로 띄우고(`detached`) 묶음째 끈다(`process.kill(-pid)`). 남은 서버는 `pkill -f "[v]ite preview --port 4173"`로 지운다. 대괄호 없이 쓰면 그 명령을 돌리는 셸 자신이 걸려 함께 꺼진다(종료 코드 144) |
| 점검 스크립트에서 장면 뒤 카드·엔딩이 오지 않음 (E23) | `Game.advance`(감기)가 `update`만 돌려 순간 줄이 흐르지 않았다 | `advance`에서도 `moments.update`를 부른다. 이 환경은 초당 몇 프레임이고 프레임 시간이 0.1초에서 잘려 순간의 기다림(실제 2.6초)이 열 배쯤 길다: 점검은 `moments.holding`이 풀리기를 기다린다. 스모크도 큰 카드가 물러난 뒤에 장면을 보낸다(CI가 느린 날 장면이 20초 안에 열리지 않았다) |
| 봇이 요툰헤임 2단계 전설에서 아홉 번까지 져 CI 봇 검증(35분)이 가끔 빨개짐 (2026-10-28) | 같은 커밋도 판마다 갈렸다. 진 도전마다 결계 안에 바깥 적 5~9마리(늑대·서리 거인·돌 던지는 거인·서리 마녀)가 들어와 있었다: 성소에서 18m 떨어진 무리가 싸움 소리에 끌려 들어오고, 결계는 전설의 적만 가뒀다. 바깥 적이 둘뿐인 판은 생명이 63% 아래로 내려가지 않고 이겼다. 16곳 중 11곳의 성소가 결계 가장자리 4~10m 밖에 무리를 둔다 | 결계가 닫힌 동안 결계 안에 세운 적과 그 적이 부른 졸개만 주인공을 본다(`Encounter.ward`, `Legend.enlist`). 나머지는 주인공이 없는 것처럼 보여 쫓던 적도 제자리로 돌아간다. 봇의 물러서기·둘레 무리 먼저 치우기는 효과가 없거나(진 횟수가 같음) 나빴다(무리가 다시 나타나 전설 시작이 32분까지 늦음) |
