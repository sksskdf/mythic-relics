# 지식 저장소

이 프로젝트를 다른 세션이 이어받을 때 필요한 것을 모아 둔 곳이다. 기획·수치의 원본은 저장소 맨 위의 문서(기획 `DESIGN.md`·시각표와 곡선 `TIMELINE.md`, 수치 `BALANCE.md` 등)이고, 지난 기획안은 [`past/`](past/)에 있다. 여기에는 **그 문서들에 없는 것**을 둔다: 지금 어디까지 왔는지, 왜 그렇게 정했는지, 일하는 순서, 이 환경의 제약, 겪은 문제.

## 새 세션은 이 순서로 읽는다

1. `CLAUDE.md`: 규칙·명령·코드 지도 (세션이 자동으로 읽음)
2. [`handoff.md`](handoff.md): **지금 상태와 다음 할 일** (가장 먼저)
3. `ROADMAP.md`의 0.2 "지금 할 일"과 지금 마일스톤 구역
4. 하려는 일에 맞는 아래 문서

## 고치는 규칙

- 일을 한 덩어리 끝낼 때마다 `handoff.md`를 고친다 (지금 상태·다음 할 일). 세션이 끊겨도 여기만 보면 이어진다.
- 사용자와 새로 정한 것은 `decisions.md`에 날짜와 함께 더한다. 기획 내용 자체는 `DESIGN.md`(시스템)·`TIMELINE.md`(시각표·곡선)에 쓰고 여기에는 결정과 이유만. 새 기획안을 따로 쓰면 만든 뒤 두 문서로 옮기고 원문은 `past/`에 둔다.
- 막혔다 풀린 문제는 `troubleshooting.md`, 환경 제약은 `environment.md`에 더한다.
- 마일스톤이 끝나면 `history.md`에 한 줄, `baselines.md`에 새 기준 수치.
