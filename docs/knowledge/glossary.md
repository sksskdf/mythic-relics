# 용어

## 옛 이름 → 새 이름 (E11에서 화면 글·데이터 설명·문서를 바꿈)

| 옛 이름 | 새 이름 | 메모 |
| --- | --- | --- |
| 클래스 | 신화 | 예: 토르의 신화. 코드 이름(`class`, `classes.json`)은 E11-05에서 `myth/`로 옮기며 정리 |
| 발현 | 신화 개방 | 코드: `manifested` |
| 클래스 레벨 1~4 | 개방 단계 1~4 | 칭호는 그대로 (토르: 천둥의 신 → 천둥군주 → 폭풍왕 → 거인의 재앙) |
| 승급 전설 | 전설 | |
| 유물 칸 | 장비 칸 | 7칸: 무기·머리·몸·손·발·장신구 둘 |
| 윤회 | 없앰 | 결정·단련·원천 숙련도 없앰 (E14) |
| 별자리 | 성좌판 (E17) | |

## 2차 스프린트 용어

| 용어 | 뜻 |
| --- | --- |
| 신화 숙련 | 그 신화권 몬스터를 잡으면 쌓이는 값. 개방 단계 1의 문턱 |
| 상시 효과 | 열린 신화가 고르지 않아도 늘 내는 효과. 여러 신화가 겹쳐 쌓임 |
| 추가 효과 | 고른 신화만 내는 효과: 고유 패시브, 궁극기, 표식(외형) |
| 고른 신화 | 1개로 시작, 보상으로 2개. 마을·성소에서 바꿈 |
| 일반 장비 | 드랍, 무작위 수치. 등급: 보통·좋음·희귀·영웅 |
| 유물 | 신·영웅마다 하나, 대장간에서 제작, 4단계 |
| 신화 재료 | 신화권 공통·신화 고유·보스 귀한 재료 |
| 원천 | 불꽃(flame)·사냥(hunt)·바람(wind)·바위(stone). 장비에 붙은 수치의 합 |
| 원천 각성 | 원천 합이 문턱 5/10/20을 넘을 때마다 열리는 효과 |
| 위협 단계 | 세계 전체 난이도 1~10. 신화 보스를 이기면 올림 |
| 원천 갈래 | 위협 단계를 올릴 때 그동안의 전투 경험을 네 원천 중 하나에 몰아 영구 원천 숙련을 올리는 것. 장비의 원천 수치에 더해져 각성 문턱에 닿기 쉬워짐 |
| 공명 | 네 원천 숙련의 최솟값만큼 모든 각성이 세짐 (골고루 키운 보상) |
| 시련 | 제약을 건 전설, 난이도 다섯, 기록 |
| 편의 자동화 | 반복이 여는 것: 자동 줍기 → 자동 분해 → 재료 자동 모음 → 성소 워프. 전투는 자동화하지 않음 |
| 한계를 깸 | 모든 신화 보스를 10단계로 이기면 상한이 풀리고 균열이 열림 |
| 균열 | 들어갈 때마다 바뀌는 층. 안쪽 리셋(매번 1층), 임시 축복은 끝나면 사라짐 |
| 성좌판 | 신화마다 별, 이웃한 별만 밝힘 |
| 빌드 상태 | 열린 신화 + 고른 신화 + 장비 + 원천 수치를 모아 능력치·효과 목록을 내는 한 곳 (E11-04) |
| 대화 장면 | 줌인, HUD 숨김, 대화 상자, 글자 쓰기, 클릭으로 완성·넘김 (E15) |
| 지역 3곳 | 신화권마다 입구 들판 → 깊은 땅 → 보스의 땅. 마을 포함 16곳 |
