# 용어

## 옛 이름 → 새 이름 (E11에서 화면 글·데이터 설명·문서를 바꿈)

| 옛 이름 | 새 이름 | 메모 |
| --- | --- | --- |
| 클래스 | 신화 | 예: 토르의 신화. 코드 이름(`class`, `classes.json`)은 E11-05에서 `myth/`로 옮기며 정리 |
| 발현 | 신화 개방 | 코드: `manifested` |
| 클래스 레벨 1~4 | 개방 단계 1~4 | 칭호는 그대로 (토르: 천둥의 신 → 천둥군주 → 폭풍왕 → 거인의 재앙) |
| 승급 전설 | 전설 | |
| 유물 칸 | 장비 칸 | 7칸: 무기·머리·몸·손·발·장신구 둘 |
| 윤회 | 없앰 | 결정·단련·원천 숙련도 없앰 (E14) |
| 별자리 | 성좌판 (E17) | |

## 2차 스프린트 용어

| 용어 | 뜻 |
| --- | --- |
| 신화 경험치 | 고른 신화만 받는 값(고른 신화가 없으면 그 신화권 신 모두). 개방 단계의 문턱. E21에서 "숙련"과 하나로 함 |
| 수집 보너스 | 열린 신화 하나마다 모든 피해 +4%, 최대 생명 +5 (E21-02, 상시 효과·메아리를 대신함) |
| 잠든 유물 | 고르지 않은 신화의 유물. 기본 수치만 내고 지속·행동 효과는 그 신화를 고르면 깨어남 (E21-04) |
| 장비 단계 | 장비가 나온 땅의 단계(장 순서). 단계마다 수치 ×1.4 (E21-03) |
| 엔딩 뒤 장치 | 깊이 고르기·맹세 다섯·균열·편의(자동 줍기 빼고). 첫 엔딩을 본 뒤 열림 (E21-06, E305-03) |
| 순간의 크기 | 강해지는 순간을 네 등급으로 보이는 규칙: 작은 알림·카드·큰 카드·장면 (E23, `src/data/moments.ts`) |
| 큰 카드 | 신화 단계·유물 벼리기 때 그 신의 색 번쩍임, 하늘 기둥, 큰북과 함께 가운데에 크게 뜨는 카드 (E23-03) |
| 떠다니는 조이스틱 | 휴대폰에서 화면 어디든 누른 채 끌면 누른 자리에 생기는 원과 손잡이. 손잡이 쪽으로 걷고, 떼면 멈춰 둘레 적을 친다 (E235-02) |
| 톡 | 휴대폰에서 짧게 누르고 떼기. 컴퓨터의 클릭과 같다: 적이면 공격, 땅이면 그곳까지 (E235-02) |
| 세로 화면 | 가로·세로 비가 4:5보다 좁은 화면(휴대폰을 세로로 든 것). 휴대폰은 세로 화면만 맞춘다 (E235) |
| 추가 효과 | 고른 신화만 내는 효과: 고유 패시브, 궁극기, 표식(외형) |
| 고른 신화 | 1개로 시작, 보상으로 2개. 마을·성소에서 바꿈 |
| 일반 장비 | 드랍, 무작위 수치. 등급: 보통·좋음·희귀·영웅 |
| 유물 | 신·영웅마다 하나, 대장간에서 제작, 4단계 |
| 신화 재료 | 신화권 공통·신화 고유·보스 귀한 재료 |
| 원천 | 불꽃(flame)·사냥(hunt)·바람(wind)·바위(stone). 장비에 붙은 수치의 합 |
| 원천 각성 | 원천 합이 문턱 5/10/20을 넘을 때마다 열리는 효과 |
| 깊이 | 세계 전체 난이도 1~10 (옛 위협 단계, E305-03). 엔딩 뒤 귀환 카드에서 다음 원정을 「그대로 / +1」로 고름. 깊이 10 원정에서 장 보스나 수호자를 이기고 귀환하면 한계를 깸 |
| 원천 갈래 | 없앰 (E21-05). 위협 단계를 올릴 때 전투 경험을 원천 하나에 몰아 영구 원천 숙련을 올리던 것 |
| 공명 | 없앰 (E21-05). 네 원천 숙련의 최솟값만큼 모든 각성이 세지던 것 |
| 시련 | 제약을 건 전설, 난이도 다섯, 기록 |
| 편의 자동화 | 반복이 여는 것: 자동 줍기 → 자동 분해 → 재료 자동 모음 → 성소 워프. 전투는 자동화하지 않음 |
| 한계를 깸 | 모든 신화 보스를 10단계로 이기면 상한이 풀리고 균열이 열림 |
| 균열 | 들어갈 때마다 바뀌는 층. 안쪽 리셋(매번 1층), 임시 축복은 끝나면 사라짐 |
| 성좌판 | 신화마다 별, 이웃한 별만 밝힘 |
| 빌드 상태 | 열린 신화 + 고른 신화 + 장비 + 원천 수치를 모아 능력치·효과 목록을 내는 한 곳 (E11-04) |
| 대화 장면 | 줌인, HUD 숨김, 대화 상자, 글자 쓰기, 클릭으로 완성·넘김 (E15) |
| 지역 3곳 | 신화권마다 입구 들판 → 깊은 땅 → 보스의 땅. 마을 포함 16곳 |

## 지금 코드에 있는 것

| 용어 | 뜻 |
| --- | --- |
| 신화권 | norse(북유럽)·greek(그리스)·china(중국)·japan(일본)·korea(한국), 마을은 hub |
| 적 역할 | brute(근접)·charger(돌격)·ranged(원거리)·guard(방어)·summoner(소환)·boss |
| 몸 종류 | giant·beast·humanoid·flyer·spirit·serpent |
| 정예 | tough(단단함)·fierce(사나움)·swift(날램), 확률 0.2, 보상 경험치 ×3·드랍 2번 |
| 지역 보스 | 거인 왕·키마이라·우마왕·야마타노오로치(머리 셋)·불가사리 |
| 성소 | 지역마다 있는 룬스톤 고리. 한가운데(화로)에 서면 원정을 마치는 귀환 카드가 뜨고, 원정이 무르익으면 빛기둥이 선다 (E304). 결계 안에서 싸우던 승급 전설은 E305-03에서 걷었다 |
| 장 | 데모 흐름의 큰 마디 (E22): 서장·제1장·막간·제2장·종장. 장마다 땅이 열리고 땅 단계(= 장비 단계)가 정해진다. 코드 `chapters` |
| 목표 한 줄 | 화면 위 가운데에 지금 할 일 하나 (E22). 장 데이터의 `goal` |
| 적 지수 | 그 땅 보통 적의 생명 배율(처음 땅 = 1). 피해는 그 제곱근 (E22, `landScale`) |
| 결계 (통로) | 아직 열리지 않은 땅으로 가는 통로 입구의 빛 벽 (E22) |
| 첫 엔딩 | 갈라진 하늘의 우트가르드의 왕을 이긴 뒤. 엔딩 뒤 장치(깊이·맹세 다섯·균열·편의)가 열린다 |
| 수련 | 공용 빌드 트리 (E236). 뿌리에서 힘·몸·손 세 갈래, 갈래 끝에 큰 마디. 정보 화면 「수련」 탭. 코드는 `training` |
| 깨달음 | 수련 마디를 익히는 점수. 경험치가 문턱을 넘을 때마다 한 점 (`insight`) |
| 마디 | 수련 트리의 칸 하나. 앞 마디를 익혀야 익힌다. 갈래 가운데의 둘 중 하나는 가지, 끝은 큰 마디 (`node`) |
