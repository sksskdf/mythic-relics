# 일시 중지한 자리 (2026-11-11, E307 0A 손 QA)

사용자가 「모든 작업 일시 중지」라고 해 손 QA 워크플로를 도중에 멈췄다. 브랜치의 코드는 검사를 통과한 `386b700` 그대로이고, 고치던 것은 아래 두 파일에만 있다. 다시 시작할 때 쓰고, 0A를 닫으면 이 폴더는 지운다.

| 파일 | 내용 |
| --- | --- |
| `qa-0a-results.json` | 손 QA 네 갈래의 항목별 판정과 근거, 고침 K·G1이 보고한 것 |
| `qa-0a-fixes.patch` | 고치던 코드 (`386b700` 기준, **검사 전**). 고침 K·G1은 끝났고 G2(카드)는 도중에 멈춰 반쯤 들어 있다 |

## 어디까지 했나

- 손 QA 넷은 끝났다. 판정: G1 손가락 입력 예 10·반쯤 1·볼 수 없음 2, G2 카드 예 9·반쯤 2, G3 지도·잘림·내 모습 예 9·반쯤 1, G4 한 판 흐름(393×659) 예 9·반쯤 4·아니오 2·볼 수 없음 1.
- 고침 K(작은 지도가 고르는 카드를 덮음, 짧은 화면의 고르는 카드, 승천 3단계 빛 고리를 저절로 띄우지 않음)와 고침 G1(손가락 입력)은 끝났다.
- 고침 G2(카드)는 도중에 멈췄고, 고침 G3·G4와 「다시 봄」은 시작하지 않았다.

## 다시 시작하는 법

1. `git apply --3way docs/knowledge/review-e307/paused-0a/qa-0a-fixes.patch` (같은 컨테이너가 살아 있으면 `git stash pop`이 같은 내용이다).
2. `qa-0a-results.json`에서 「예」가 아닌 항목을 읽고, G2에서 반쯤 고친 것(`src/ui/portrait.css`·`return.css`·`pickGate.ts` 둘레)부터 확인한다.
3. 남은 고침(G2·G3·G4)을 끝내고 `npm run check` → 393×852·393×659에서 다시 본 뒤 커밋한다.
4. 그 뒤는 `handoff.md`의 「다음 할 일」 차례 그대로다.
